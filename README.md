
# pygameproj

Проект **pygameproj** был разработан в рамках учебной программы [Яндекс Лицея](https://yandexlyceum.ru/) совместно с другим студентом — [Zyrome64](https://github.com/Zyrome64). Это учебный проект, демонстрирующий применение библиотеки Pygame для создания игр.

## О проекте

Проект посвящен созданию игры с использованием возможностей библиотеки Pygame. Основные элементы игрового процесса включают:
- Управление игровым персонажем.
- Обработка пользовательского ввода.
- Реализация базовой физики и взаимодействия объектов.
- Графическое оформление с использованием спрайтов и анимаций.

### Основные функции
- **Движение персонажа**: Реализовано управление с помощью клавиатуры.
- **Столкновения объектов**: Обработаны взаимодействия между элементами игры.
- **Графика**: Использование Pygame для отрисовки объектов и фона.

## Используемые технологии

- **Язык программирования**: Python
- **Библиотека**: Pygame

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/GameTrue/pygameproj.git
   ```
2. Установите Python 3.6 или выше.
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите проект:
   ```bash
   python main.py
   ```
